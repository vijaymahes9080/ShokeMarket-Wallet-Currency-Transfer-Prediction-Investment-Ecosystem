## 🌐 GitHub Pages Deployment Guide

To enable GitHub Pages in your repository settings:
1. Go to **Settings** ➔ **Pages** in your GitHub repository.
2. Under **Source**:
   - Option A: Select **Deploy from a branch** ➔ Branch: `gh-pages` / `/ (root)` ➔ Click **Save**.
   - Option B: Select **GitHub Actions** (Automated build workflow configured via `.github/workflows/deploy.yml`).

Live Platform URL:
`https://vijaymahes9080.github.io/ShokeMarket-Wallet-Currency-Transfer-Prediction-Investment-Ecosystem/`

### 1. 💳 Multi-Currency Wallet Engine
- Hold, convert, and manage 6 global fiat currencies (INR ₹, USD $, EUR €, GBP £, JPY ¥, AED 🇦🇪).

### 2. 💸 Wise-Like Remittance System
- Instant cross-border payment settlement.

## 🚀 Quick Start Guide

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/vijaymahes9080/ShokeMarket-Wallet-Currency-Transfer-Prediction-Investment-Ecosystem.git
cd ShokeMarket-Wallet-Currency-Transfer-Prediction-Investment-Ecosystem
npm install
```

### 2. Launch Local Development Server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### 3. Run Production Build
```bash
npm run build
```

### 4. Start Backend Server
```bash
npm run server
```
